# Privacy-Preserving EEG Classification with CKKS

A research project exploring **privacy-preserving ADHD classification from EEG connectivity data** using **homomorphic encryption (CKKS)**.

The project investigates the use of an **HE-compatible neural network** for performing inference on encrypted EEG-derived connectivity data while studying the trade-offs involved in privacy-preserving computation.

## Tech Stack

* Python
* PyTorch
* scikit-learn
* OpenFHE / CKKS
* NumPy
* Pandas
* Matplotlib

## Data

The EEG dataset and associated private data are **not included in this repository** and will remain private until the associated research is published.
